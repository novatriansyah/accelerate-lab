# Antigravity / Gemini Workspace Instructions

## Strict TDD Adoption
Always enforce **Strict Test-Driven Development (TDD)**:
1. **Red:** Write failing tests first before modifying production code, views, or styles.
2. **Green:** Write minimal code to pass the tests.
3. **Refactor:** Clean and optimize while keeping 100% test pass rate.
